# PaperPulse · 智研脉

> 制造顶刊 × 计算机前沿（大模型 / 知识图谱 / 计算机视觉 / 多模态 / 具身智能）实时学术追踪与十维深度解析平台

## 核心特性
- **类微博实时学术流**：按日期动态追踪制造与计算机顶刊前沿，支持通过 arXiv ID / DOI / 关键词在线抓取并自动解析入库。
- **十维学术逻辑拆解**：覆盖研究背景、核心问题、研究现状、现存局限、提出方法（含交互式架构图）、实验验证、数据集来源（公开/自建/混合）与构建管线、对比与消融实验交互图表、研究结论、本文局限与未来展望。
- **全景可视化看板**：领域 × 技术方向交叉热力矩阵、数据集构建分布、每日入库趋势及交互式知识关联星图。
- **持久化存储与完整 CRUD**：基于 Node.js 24 内置 SQLite（WAL 模式）提供文献与学术批注的增删改查及点赞/收藏/BibTeX 引用持久化。

## 本地运行与构建
```bash
npm install
npm run typecheck
npm run build
npm start
```
默认访问地址：`http://localhost:3000`

## 账户与文献互动
- 必须登录或注册后才能查看公共池、成员目录、个人知识库和原文图表；API 和本地图表资源也执行登录校验。
- 每篇文献显示实名账户足迹：头像、用户名、访问次数、有效阅读时长、最近活动、评论、点赞和收藏。气泡图展示前16名活跃成员，完整列表可查看所有成员。
- 信息流可见累计3秒形成一次访问；精读页打开形成一次访问。后台、失焦和被精读弹窗遮挡的信息流暂停计时；每10秒以及切后台、关闭时上报。时长表示平台内有效停留，不包含外部 PDF 网站阅读。
- 每次阅读以会话ID和累计秒数上报，服务端去重并限制时长不超过实际经过时间。点赞和收藏可取消，评论支持回复与点赞，作者及管理员可编辑和删除评论。
- 收藏和阅读状态属于当前账户；公共池可看到其他成员的互动，成员目录支持查看其收藏库和互动足迹。界面每30秒刷新其他成员的数据。
- 阅读和互动记录存储在 SQLite，Docker 的 `./data:/app/data` 挂载确保容器重建后保留。已有历史数据不会推算过去未记录的访问时长。

## Docker 常驻部署
```bash
python3 translation/install_model.py
docker compose up -d --build
docker compose ps
```
默认局域网地址：[PaperPulse](http://10.206.58.217:13001)，部署目录 `/home/wangji/paperpulse-platform`。可在服务器 `.env` 中设置 `PAPERPULSE_PORT`（13001–14000）。容器配置 `restart: unless-stopped`，健康检查为 `/api/health`；该公开接口只返回服务健康信息。
升级前应使用 SQLite backup API 备份数据库，并保留旧镜像以便回滚；不要用本地数据库覆盖服务器的 `data` 目录。账户密码、服务器密码和 GitHub 令牌不应写入仓库。

管理员首次初始化请在服务器 `.env` 配置 `BOOTSTRAP_ADMIN_PASSWORD`，不会再创建使用公开演示密码的管理员。已有使用旧演示密码的管理员会在升级时更换为该配置并注销旧会话；其他已配置密码的账户保留原密码。

## 管理员用户管理
使用服务器配置的 `admin` 账户登录，在顶部「用户管理」中新增、搜索、编辑和删除账户，可修改用户名、姓名、标签、角色或重置密码。管理员角色拥有用户管理能力，普通成员不能管理其他账户。重置密码会注销目标用户的旧登录会话；系统 `admin` 账户不能删除、改名或降为普通成员。管理员密码仅保存在服务器配置中，不写入前端或 GitHub。

## 导航、研究分类和更新展示
导航与搜索框固定在单行，搜索宽度256px；窄屏时整条导航横向滚动，不换行。公共池提供最近12篇入库动态、原图缩略图和5秒轮播，支持暂停及手动切换。
研究方向分别包含多智能体、人智协作、产品设计与设计认知、生成式设计与优化、交互设计与用户体验、可持续设计。新增设计期刊来源：JMD、Design Studies、Research in Engineering Design、Computer-Aided Design、AI EDAM、Design Science，以及IJPR。来源ID由OpenAlex按ISSN核对；设计期刊元数据缺少摘要时保留待解析状态。
可运行 `npx tsx server/importDesign.ts` 执行一次最近一年设计期刊初始导入（仅补全尚未收录的期刊，每刊最多一篇），正常自动同步继续更新这些来源。

## 权限与个人统计
- 管理员：公共文献池增删改查、导入/解析/附件上传、批量删除、数据库压缩、自动入库上限管理；默认自动入库上限1000篇。删除同步清理本地资源，删除记录阻止自动再次收录；手动重新录入可以恢复收录。
- 普通成员：账户页面和 `/api/users` 仅显示本人；`/api/analytics` 仅能获取本人统计。个人阅读看板包括有效阅读气泡图、访问次数排行、关键词热图和研究方向分布。管理员可切换为指定成员或全体统计。公共文献页的社交互动展示沿用团队共享机制。
- 个人知识库使用全宽工作区，综述矩阵明确列出研究背景、核心问题、方法、结论、数据集、本人思考和阅读进度；看板同样列出四项研究摘要。普通成员从公共池收藏，不直接写入公共文献池。

验证命令 `npm run typecheck` 同时检查前后端，`npm test` 覆盖管理员文献CRUD、附件删除、普通成员权限与个人统计隔离，以及原有社交与持久化功能。

## 抓取与解析质量升级
- 当前年度优先：CVF CVPR、ACL Anthology主会和PMLR ICML官方开放论文集，保留官方页面、PDF、可用的代码仓库链接及来源提供的日期精度。只给年份的论文不会虚填月日。DOI检索增加Crossref回退，支持官方论文页链接导入。
- PDF正文解析使用PyMuPDF，提取摘要、引言、方法、实验和结论段落；保留解析状态、页数、来源及未获取内容的说明。摘要拆解与原文数值分开，缺少证据时不生成对比数值或消融结果。
- 每篇文献提供关键词（作者关键词、自动提取或管理员维护），可通过顶部搜索检索；个人关键词热图也统计这些词。
- 公共池提供文献时间线，按发表或入库月份筛选；默认展示本年度，可切换全部年份。
- 修复旧表格内的相对SVG object被当作本站页面加载的问题：原文资源下载为静态图片，HTML只允许表格、文本和经校验的本地图片；移除object/iframe/embed及活动内容。缺失附件返回404，不再回退为平台首页。启动时清理旧记录，前端再执行一次静态表格净化。

执行 `npx tsx server/refreshResearch.ts` 可进行一次今年官方开放论文补充（最多24篇）及旧记录修复。每次遵守自动入库上限，按标题和DOI去重，保留管理员删除标记。来源超时、未公开或PDF不可用时会记录说明，允许以后重试，不以空结果覆盖已有原图。

抓取增加经过来源和年份校验的元数据缓存，以及已验证PDF的本地缓存。站点短暂超时仍可解析已经成功获取的原文，避免重复下载；PDF缓存计入文献附件占用，删除文献时一起清理。`server/refreshResearch.ts --cached` 可复用已核验的年度官方元数据缓存进行补充和重试。
已缓存且验证通过的原文PDF可从文献卡片的「站内原文PDF」在局域网内打开，减少对外部站点可达性的依赖；原始来源链接仍保留。

## 学术中文翻译与质量检查
Docker Compose 使用独立的本地 Qwen3-4B-Instruct-2507 模型，通过 Ollama 和私有翻译API运行。已停用旧 Argos 模型，不会在请求失败时退回旧译文。需要可用的 NVIDIA GPU（本服务器实测约4GB显存）及 NVIDIA Container Toolkit；初次下载量化模型约2.5GB，不需要云端API密钥或按次付费。模型与运行缓存保存在 `translation-llm/`，不提交Git。只有网页端口13001对局域网开放。

首次安装仍执行 `python3 translation/install_model.py`，该脚本启动模型服务并拉取 `qwen3:4b-instruct-2507-q4_K_M`；然后执行 `docker compose up -d --build`。`LOCAL_TRANSLATION_URL` 可指向兼容的私有 `/translate` 接口：POST `{q:string|string[]}`，返回 `{translatedText:string|string[]}`。

翻译使用制造、机器人和人工智能术语约束，逐段处理，保持数字、公式、引用和模型名称。服务端和应用端均检查异常重复、长度、数值丢失及生成的对话/代码标记；未通过的结果不写入译文缓存。批次失败时按完整句子缩小范围重试，不通过则保留可用原文并标记待重试，不显示虚假的中文完成状态。模型版本独立缓存，旧版错误译文不会作为新版缓存命中。

每个展示段落记录原文及对应译文；重新翻译以原文为依据，保留人工修改的中文。页面可展开「原文与译文核对」。自动翻译仍可能存在术语或句意偏差，质量检查不等于人工学术审校；图像中的原文文字保留原貌。

`docker compose exec paperpulse npx tsx server/repairTranslations.ts` 从原PDF和旧缓存中的英文来源恢复并更新已有译文，异常重复的论文优先处理。可用 `--paper=<ID> --force` 单篇重试。修复过程保留评论、阅读、收藏、上传者和原始附件，并在保存前检查并发编辑；完成后输出未完成的文献ID。`server/localizeLibrary.ts` 可执行常规补译，后台每分钟重试两篇未完成的文献。

PDF提取同时过滤运行页眉、作者通讯信息、收稿出版元数据和arXiv水印，识别期刊常见的间隔字母摘要标题，截取在完整句子边界。无法确认的正文仍需结合站内PDF核对，不生成缺失实验值。

## 用户与管理员上传PDF
登录后，所有成员均可通过顶部「上传PDF」选择或拖入单篇不超过32MB的文献，并选择是否同时收藏到自己的知识库。文件与解析任务进入持久化后台队列，关闭窗口后继续运行，重启后恢复；重新打开上传窗口可查看进度。普通成员仅能查看自己的任务，管理员可查看所有任务。所有成功入库的论文及其原始PDF均进入公共池，沿用现有关键词、时间线、精读、社交与统计功能，并显示上传者和上传时间。公共文献编辑、删除、图表补充仍由管理员管理。

系统读取PDF标题、作者、DOI、日期、摘要、章节和关键词，尝试通过Crossref核对期刊、作者单位及发表日期；题名一致时才采用在线元数据。自动判断研究方向、领域及数据集的公开/自建/混合来源。无法确认的期刊、日期、作者和数据来源会明确提示，不以PDF创建日期冒充发表日期，不为未匹配的论文强行指定大模型方向。正文与原文图表说明使用已有免费中文翻译服务。

正文提取前40页；扫描件尝试中英文OCR，最多识别8个扫描页。从前18页提取最多6张关键图、4张原文实验表格，保留原始图表截图和图注，不编造实验指标。提取失败的部分有说明，完整PDF仍可在站内阅读。扫描、复杂排版、公式和图表中的文字需要结合原文核对。运行环境使用PyMuPDF和Tesseract，Docker镜像已包含对应依赖。

文件SHA256、DOI和规范化标题去重，重复文献定位已有条目；仅以文件名推断的标题不参与标题去重。每人最多3个待处理任务，全站最多24个，遵守公共池容量和管理员删除记录。原始文件仅在登录后可访问。暂存文件在成功或失败后清理，原始PDF与原图纳入管理员附件存储统计，删除论文时同步清理。

接口：`POST /api/papers/upload-pdf` 使用 `application/pdf` 原始文件流，`X-File-Name` 为URL编码文件名，`X-Add-To-Kb: 0` 可关闭自动收藏；返回202和任务ID。`GET /api/pdf-imports` 和 `GET /api/pdf-imports/:id` 查询任务，完成后通过原有文献接口查看结果。
