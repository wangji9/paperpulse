# PaperPulse · 智研脉

> 制造顶刊 × 计算机前沿（大模型 / 知识图谱 / 计算机视觉 / 多模态 / 具身智能）实时学术追踪与十维深度解析平台

## 核心特性
- **类微博实时学术流**：按日期动态追踪制造与计算机顶刊前沿，支持通过 arXiv ID / DOI / 关键词在线抓取并自动解析入库。
- **十维学术逻辑拆解**：覆盖研究背景、核心问题、研究现状、现存局限、提出方法（含交互式架构图）、实验验证、数据集来源（公开/自建/混合）与构建管线、对比与消融实验交互图表、研究结论、本文局限与未来展望。
- **全景可视化看板**：领域 × 技术方向交叉热力矩阵、数据集构建分布、每日入库趋势及交互式知识关联星图。
- **持久化存储与完整 CRUD**：基于 Node.js 24 内置 SQLite（WAL 模式）提供文献与学术批注的增删改查及点赞/收藏/BibTeX 引用持久化。

## 本地运行与构建
```bash
npm install
npm run typecheck
npm run build
npm start
```
默认访问地址：`http://localhost:3000`
